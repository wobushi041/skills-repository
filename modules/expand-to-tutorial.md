# Expand To Tutorial

Use this module when the user wants concise notes expanded into a teaching-style article.

## Intent

- Explain concepts step by step
- Add examples and usage context
- Keep the result suitable for long-term knowledge-base reading

## Suggested Structure

- What it is
- Why it matters
- Core concepts
- How it works
- Example
- Common mistakes
- Summary

## Rules

- Preserve the original point of view unless the user asks for reframing.
- Label added knowledge as supplemental when it goes beyond the user source.

## Must Also Read If

- The destination is an existing Feishu doc:
  - `existing-doc-safe-edit.md`
- The source is a PDF:
  - `pdf-to-feishu.md`
- The source is a Word/docx file:
  - `word-to-feishu.md`
- The source is Markdown or TXT:
  - `markdown-to-feishu.md`
- The tutorial includes comparison tables, parameter tables, or checklists:
  - `sheet-table-handling.md`
